frinZ-rs memo
=============

1. GitHub へアップロードする方法

通常の更新:

```bash
git status
git add .
git commit -m "変更内容"
git push
```

補足:
- 今の branch は `main`
- `origin` は GitHub に設定済み
- `git commit` だけでは GitHub には反映されない
- GitHub に送るのは `git push`


2. crates.io へアップロードする方法

この workspace では crates.io に公開するのは `frinZ` だけ。
`tools` package (`frinZ-tools`) は `publish = false`。

事前確認:

```bash
cargo check -p frinZ --all-targets
cargo package -p frinZ
```

初回だけ必要:

```bash
cargo login
```

公開:

```bash
cargo publish -p frinZ
```

補足:
- 公開対象は `src/frinZmain/`, `README.md`, `LICENSE`
- `cormerge`, `gfrinZ`, `corshow`, `bandscythe`, `pulsar_gating` は crates.io には載らない


3. ローカルでコンパイルする方法

workspace 全体:

```bash
cargo check --workspace --all-targets
cargo build --workspace
```

公開用 frinZ のみ:

```bash
cargo check -p frinZ --all-targets
cargo build -p frinZ
```

tools のみ:

```bash
cargo check -p frinZ-tools --all-targets
cargo build -p frinZ-tools
```


4. 各プログラムの実行例

frinZ:

```bash
cargo run -p frinZ --bin frinZ -- --help
```

cormerge:

```bash
cargo run -p frinZ-tools --bin cormerge -- --help
```

gfrinZ:

```bash
cargo run -p frinZ-tools --bin gfrinZ -- --help
```

corshow:

```bash
cargo run -p frinZ-tools --bin corshow -- --help
```

bandscythe:

```bash
cargo run -p frinZ-tools --bin bandscythe -- --help
```

pulsar_gating:

```bash
cargo run -p frinZ-tools --bin pulsar_gating -- --help
```
